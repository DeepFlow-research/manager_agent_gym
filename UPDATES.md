# Updates made for adaptive replanning under exogenous changes

Changes relative to the original MA-Gym code, grouped by component. The current direction is **adaptive
replanning under exogenous changes** (outages and rate limits; rows marked "Specialist loss"; design in
[`research/decisions.md`](research/decisions.md), thresholds in [`research/preregistration.md`](research/preregistration.md)). Rows
without that mark describe changes kept from the earlier work (bug fixes, checklists, the metrics, the manager context log, the dashboard and run scripts); the join/leave benchmark itself was removed.
Status is **Done** (in the working tree) or **Planned** (decided, not built). On 2026-10-21 the first specialist-loss implementation (package, scripts, tests, converted workflows) was no longer in the working tree, so its rows are **Planned**: they are the specification to rebuild against `research/Project Proposal.pdf`.
